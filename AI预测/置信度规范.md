# 置信度标注规范（两维）

> 本文件是 AI预测 专题 5 份文档共用标注规范。2026-10 起，原有的 🟢🟡🔴 /【高】【中】【低】两套并存的单维标记统一为本文的两维体系。
>
> **为什么要改**：单维标记回答的是"我有多确信"，而不是"证据有多强"。结果是大量标为"高"的判断，依据其实只是"机制推演看起来成立"，与有统计支撑的判断被读成同一等级。现在把两件事拆开。

---

## 一、两个维度

### 维度一：证据类型（这条判断靠什么支撑）

| 类型 | 含义 | 判定标准 |
|------|------|----------|
| **数据** | 有可指认的统计、历史记录或正在发生的事实支撑 | 能说出数字的出处与口径；或能指出一个已记录在案的真实事件 |
| **机制** | 机制链条成立、方向可推，但无直接数据 | 能把从前提到后果的中间步骤一步步写出来，每一步都有独立成立的道理 |
| **类比** | 依据历史类比外推 | 依赖"AI 与前人通用技术可比"这一前提；结论随该前提失效而失效 |
| **推测** | 分叉尚未发生，取决于尚未确定的路径 | 无法写出中间步骤，只能指出几条可能的分叉 |

### 维度二：确信度（这条判断有多大概率成立）

| 等级 | 含义 |
|------|------|
| **高** | 在多个案例中反复成立，或有直接数据；即使前提被修正，结论方向大概率不变 |
| **中** | 机制清楚、方向可推，但规模或时点依赖尚未兑现的制度条件 |
| **低** | 机制讲得通但缺经验支撑，默认按假说处理 |

---

## 二、标记语法

```
【数据·高】  【数据·中】  【数据·低】
【机制·中】  【机制·高】  【机制·低】
【类比·中】  【类比·低】
【推测·低】
```

**规则**：

1. 标记必须带证据类型，**不允许只写确信度**。写【高】而不写证据类型的，等于没标。
2. 标记紧跟它所修饰的命题，或作为独立行标注整节/整段的置信度。
3. 一个段落里包含多个不同性质的命题时，分别标注，不要用单一标记覆盖全段。
4. **"高"是一个需要理由的资格。** 写【…·高】时，正文或紧邻位置必须能指出数据出处或反复出现的案例；指不出来的，一律降为【机制·中】或【类比·低】。
5. 凡是依赖历史类比外推的判断，一律标【类比·…】，并在第五部分「历史类比的适用条件」里登记其失效条件。
6. 涉及时间表的判断（"20XX–20XX 年"）至少是【机制·中】或【类比·中】，不得标【数据·高】——时间表依赖尚未兑现的条件。

## 三、从旧标记迁移

| 旧标记 | 迁移方式 |
|--------|----------|
| 🟢 | 确信度可保留为"高"，**但必须重新判定证据类型**。旧 🟢 中大量是"机制推演看起来成立"，不能迁到【数据·高】 |
| 🟡 | 确信度"中"，证据类型需逐条判定 |
| 🔴 | 确信度"低"，证据类型需逐条判定 |
| 【高】/【中】/【低】/【中偏低置信度】 | 同上；【中偏低置信度】拆为【机制·低】或【推测·低】 |

**旧 🟢 的重新判定清单**（迁移时逐条对照）：

- 指的是已经发生的事实、已公布的政策、已测得的数字 → **数据·高**
- 指的是一条可完整推演的机制链 → **机制·高**（不要自动降级为"中"——机制链若每一步都成立，"高"是正当的）
- 指的是"以前有过，这次也会" → **类比·中** 或 **类比·低**
- 指的是"如果 A 发生则 B" → **机制·中**
- 指的是尚未发生的分叉 → **推测·低**

---

## 四、每节末尾的「预测的脆弱点」

这一节是本专题最重要的自我约束，保持不变。它回答的是**"什么条件会推翻本节判断"**，与置信度互补：

- 置信度说的是"这条判断有多强"
- 脆弱点说的是"什么会让它失效"

【数据·高】的判断同样可以有脆弱点（例如数据本身的口径可能过时）。脆弱点不是置信度的反面，是它的补充。

## 五、使用检查清单

写完一节后自查：

- [ ] 本节的每个判断都有标记吗？
- [ ] 有没有只写确信度、漏了证据类型的？
- [ ] 标【…·高】的地方，能不能在文中指出数据出处或反复出现的案例？
- [ ] 依赖历史类比的判断，是否标了【类比·…】？是否在「历史类比的适用条件」里登记？
- [ ] 涉及时间窗的判断，确信度是不是至少"中"？
- [ ] 本节末尾的「预测的脆弱点」写了吗？
