# 近现代西方社会学与思想家知识库

> 一个关于近现代西方社会学与思想家的深度复述知识库。当前收录 **9 位思想家、42 部主要著作**的完整论述，每部 2–3 万字。
> 覆盖古典社会学奠基、社会学理论化、法兰克福学派、后结构主义、自由主义、当代流动性研究、后殖民批评等主要传统。

---

## 一、项目简介

### 这是什么

一个**学术写作型知识库**：不是书摘汇编，也不是条目式百科，而是对每部经典著作做一次完整的"读透式"重构——先还原写作时的历史语境，再拆解核心论点、关键概念与方法论，最后评估其学术接受度、后续影响、与其他著作的关联，以及它在今天的解释力。

每部著作的论述由固定板块拼装而成，因此**不同思想家、不同学派的条目可以横向并排比较**。这一点是本库相对于单本读书笔记的核心价值。

## 二、快速开始

### 路径一：只想了解"现代性批判"

按 **涂尔干 → 马克思 → 涂尔干**… 的顺序会绕。推荐直击四部核心：

1. [齐格蒙特·鲍曼-主要著作详述.md](齐格蒙特·鲍曼-主要著作详述.md) —《现代性与大屠杀》《流动性现代性》两章，回答"现代性到底出了什么问题"
2. [米歇尔·福柯-主要著作详述.md](米歇尔·福柯-主要著作详述.md) —《规训与惩罚》《性史》，权力如何渗透到日常层面
3. [尤尔根·哈贝马斯-主要著作详述.md](尤尔根·哈贝马斯-主要著作详述.md) —《交往行为理论》《现代性的哲学话语》，给出一个修复方案
4. [弗里德里希·哈耶克-主要著作详述.md](弗里德里希·哈耶克-主要著作详述.md) —《通往奴役之路》，同一问题的相反答案

四者合看：哈耶克说秩序是最高的，鲍曼说现代性恰恰在溶解一切可依附的结构，福柯描述机制，哈贝马斯提出交往层面的第三条路。

### 路径三：做读书笔记

1. 先读对应顶层文件的**「作家简介」+「主要著作概览」+「核心理论框架」**三节（约 20–30 分钟），建立人物坐标系
2. 在**「详细论述」**里挑与你问题最相关的那一部，只读它的「核心论点」「关键概念详解」「方法论」三节
3. 抄**「关键概念详解」**里的定义进自己的术语表；抄「学术接受与批评」里的反对意见，避免把经典当教条
4. 用「与其他著作的关系」「交叉对照」两节做横向坐标——知道一个概念从哪来、跟谁对话
5. 收尾读「当代意义」，检验它今天还能不能用
6. 全局导航查 [近现代社会学与思想家综合图谱.md](近现代社会学与思想家综合图谱.md)

## 五、辅助索引文件说明

三份辅助文件分工不同，**不是同一个东西的三种写法**，按用途选：

### 1. [近现代社会学与思想家综合图谱.md](近现代社会学与思想家综合图谱.md) — 全局地图 / 规划书

- **作用**：回答"整个领域还缺什么、我下一步该做谁"
- **内容**：按 15 类学派/传统列出 71 位思想家；对已有地图做结构性批评（找出"团结与仪式""当代现实""全球与种族""日常与情感""政治决断"五个空缺）；按议题给出补位推荐；追踪完成情况与学派覆盖度
- **适合**：选题、找对照组、评估研究位置
- **不提供**：具体论证内容

### 2. [思想家复述合集-主旨与逻辑图.md](思想家复述合集-主旨与逻辑图.md) — 概念速查 / 逻辑链图

- **作用**：回答"这几位到底在说什么，主线怎么走"，以及"面对这个具体问题该调用谁"
- **内容**：八节——①十位人物的一句话主旨与核心概念关键词；②每人"母题"与逻辑链（起点 → 中间环节 → 结论）；③核心概念交叉对照；④每人核心问题清单（可直接当研究问题用）；⑤十位思想家在八个坐标轴上的"思想光谱"（真理的位置、自由的位置、权力的位置等）；⑥可复用的"思想诊断工具"；⑦复用提示；⑧交叉引用
- **适合**：快速复习、写引言、做概念对比、跨学派写作时的引子、找研究切口
- **特点**：短（8 节、约 2.1 万字），是**三层压缩法的第三层**——详述层（每本 2–3 万字）保留论证细节，主旨层保留核心论点，本文件只保留可引用的逻辑骨架
- **覆盖**：保罗·格雷厄姆、马克思、布尔迪厄、福柯、哈耶克、韦伯、涂尔干、鲍曼、哈贝马斯、萨义德（十人）

### 3. [黑客与画家-详细复述.md](黑客与画家-详细复述.md) — 非社会学专题补充

- **作用**：保罗·格雷厄姆《黑客与画家》全书 15 章 + 后记的完整复述
- **内容**：为什么书呆子不受欢迎、好玩的看法、如何创造财富、设计者的品味、程序设计语言、城市的意义，以及"品味如何被创造"的隐线

- **说明**：它不属于社会学经典谱系，是本库唯一一本非思想家著作

## 八、写作与维护约定

### 每部著作的固定 10 板块结构

所有详述（无论哪部著作、哪位思想家）均按以下顺序展开，板块名统一：

| # | 板块 | 内容要点 |
|---|------|---------|
| 1 | **背景与语境** | 写作的历史条件、学术争论现场、作者的处境与动机 |
| 2 | **核心论点** | 全书的主命题，用一两句话可复述 |
| 3 | **关键概念详解** | 逐条拆解核心术语，定义、来源、边界、常见误用 |
| 4 | **方法论** | 研究设计、材料来源、分析路径、证据类型 |
| 5 | **主要内容** | 按结构或主题展开的实质内容 |
| 6 | **学术接受与批评** | 传播史、学术界评价、主要反驳与其效力 |
| 7 | **深远影响** | 对后续研究、学科建制、现实政策或公共讨论的作用 |
| 8 | **与其他著作的关系** | 与作者其他作品的互文，以及在作者思想脉络中的位置 |
| 9 | **交叉对照** | 与本库其他思想家核心概念的横向比较 |
| 10 | **当代意义** | 今天如何读、适用边界与失效风险 |

### 体量与文风

- 每部著作 **2–3 万字**；分章原稿（`子目录/NN-*.md`）在 4–12 万字区间，合并后统一裁剪到顶层稿
- 面向有阅读耐心的普通读者：概念必须先定义再使用，不默认读者读过原著
- 允许并鼓励明确表态——哪些论断已被反驳、哪些至今悬置、哪些被误用
- 避免把经典写成颂词；「学术接受与批评」板块不得缺席或敷衍

### 命名与目录

- 顶层文件统一命名 `<人物全名>-主要著作详述.md`，人物全名用中点分隔（`·`）
- 子目录用英文小写：`marx/`、`bourdieu/`、`foucault/`、`hayek/`、`weber/`、`durkheim/`、`bauman/`、`habermas/`、`said/`
- 章节文件命名 `<两位序号>-<英文短名>.md`，序号即著作在作者书目中的顺序
- `intro.md` 固定存放导论，结构为：作家简介 → 主要著作概览 → 核心理论框架
- 新增人物时，同步在 `近现代社会学与思想家综合图谱.md` 第六部分的完成情况追踪表中登记，并更新本 README 的总表与文件清单

### 维护节奏

1. 在子目录写分章原稿 → 2. 合并进顶层详述文件 → 3. 更新综合图谱的完成追踪表 → 4. 更新本 README 的总表与文件清单 → 5. 在图谱附录 B 追加维护日期记录
